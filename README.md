# Парсер Погоды 🌤️

Простой консольный парсер погоды, написанный на Python. Получает текущую температуру, описание и влажность по названию города.


## 🚀 Установка и запуск

```bash
git clone https://github.com/your_username/weather-parser.git
cd weather-parser
pip install -r requirements.txt
python weather_parser.py
```

## 💡 Пример

```
Введите город: Москва
🌆 Город: Москва
🌡 Температура: 14°C
📖 Описание: Облачно
💧 Влажность: 58%
```

## Важно

Данные берутся из Google, поэтому они могут быть недоступны при частом запросе или изменении верстки страницы.
